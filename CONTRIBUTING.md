# Contributing

Research contributions are welcome, but every technical claim should include enough provenance to reproduce it.

## Finding format

For each new finding record:

1. ECU HW/SW identifier.
2. Input hash(es), not the full proprietary binary.
3. Symbol/function name where known.
4. Reference source and reference address.
5. Target address/candidate address.
6. Method: exact signature, local alignment, xref, disassembly, runtime log, etc.
7. Confidence: `CONFIRMED`, `LIKELY`, `HYPOTHESIS`, `UNTESTED`.
8. Reproduction steps.

Do not commit VINs, immobilizer data, EEPROMs, commercial dumps or copyrighted calibration projects without explicit redistribution rights.
